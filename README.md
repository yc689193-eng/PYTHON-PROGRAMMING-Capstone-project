# TREASURE ADVENTURE GAME

# About the Project
Treasure Adventure is a simple text-based adventure game developed using Python. In this game, players explore forests, fight monsters, search for hidden treasures, and collect gold coins while managing their health.

# The main objective is to collect as much gold as possible and survive the adventure.

# Features
--> Explore the forest and discover random events.
--> Fight monsters using random attack damage.
--> Search for hidden treasures and earn gold coins.
--> Check player health and gold status.
--> Exit the game whenever you want.
--> Random events make every game different.
   
# Technologies Used
--> Python 3
--> Random Module

# Concepts Used
--> Variables and Data Types
--> Conditional Statements (if-elif-else)
--> While Loop
--> User Input (input())
--> Random Module
--> Basic Game Logic

# Game Menu
Option	Description
1	Explore the forest
2	Fight a monster
3	Search for treasure
4	Check player status
5	Exit the game

# Game Rules
--> The player starts with 100 health points.
--> The initial gold balance is 0.
--> Exploring the forest may provide health, gold, or a monster encounter.
--> Fighting monsters can reward the player with gold or reduce health.
--> Searching for treasure provides random gold rewards.
--> The game ends when health reaches zero or the player exits.
